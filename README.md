# Лабораторная работа №1: Определение ОС и сбор системных параметров
## Disclaimer
This repository is created solely for educational purposes as part of a university laboratory assignment. The script does not collect, store, or transmit any personal data, credentials, or sensitive user information. All data is processed locally on the user's machine and saved into a local JSON file.
## Описание
Программа представляет собой скрипт на языке Python, который автоматически определяет тип текущей операционной системы (Windows, Linux и др.) и собирает базовые технические параметры окружения. 
Результат работы сохраняется в структурированный файл 'system_info.json' в текущей директории.
## Перечень собираемых параметров
* 'operating_system' — Имя операционной системы, определенное скриптом (Windows, Linux или Unknown).
* 'os_version' — Полная версия сборки операционной системы.
* 'computer_name' — Сетевое имя компьютера (имя хоста).
* 'architecture' — Архитектура процессора.
* 'processor' — Название и модель процессора (если операционная система предоставляет эти данные).
* 'logical_cpu_count' — Количество доступных логических ядер процессора.
* 'current_directory' — Абсолютный путь к папке, из которой был запущен скрипт.
* 'collection_time' — Точная дата и время запуска скрипта в формате ISO 8601 с учетом часового пояса.
## Использованные модули
Все модули являются стандартными и входят в состав Python:
* 'platform' — для определения характеристик ОС, архитектуры и процессора.
* 'os' — для получения текущей директории и количества ядер ЦП.
* 'socket' — для безопасного получения сетевого имени машины.
* 'json' — для сохранения данных в формате .json.
* 'datetime' — для фиксации времени генерации отчета.
## Инструкция по запуску
После запуска скрипта в папке проекта появится файл 'system_info.json'.
